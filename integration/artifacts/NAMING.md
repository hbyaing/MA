# D27：沿用铁砧命名

用户已选择原版铁砧命名；来源专用赐名界面、命名令牌和32字限制不接入交付版。正常命名完全走现有 `AnvilMenu` 输入、预览、经验费用、领取和 ItemStack 自定义名称存储，不额外增加客户端界面或网络包。

核查目标现有 `BoundEquipmentCrafting` 只管理合成网格；`SpiritSwordAnvil` 只处理其自身灵剑类型，未保护新增法宝。新增 `ArtifactNaming` Forge 自动事件订阅器仅覆盖左右任一输入为六类法宝的铁砧操作：复用 `EquipmentBond.canConsume` 校验实际操作者与唯一 `HeartOwner`；阻止把有主右侧祭品并入无主左侧产物而洗掉主人。允许的操作交回原版，不设置新产物、不覆写成长标签，不重复实现认主树。

`AnvilUpdateEvent` 的取消语义已从本地 Forge 47.4.10 sources 缓存确认：取消时输出为空，原版逻辑不执行；无需总注册接线，静态 `@Mod.EventBusSubscriber` 自动注册。

新增两个真实 AnvilMenu GameTest，覆盖六类法宝重命名预览与实际点击领取、超过来源32字但仍在原版上限内的名称、原版费用、保存重载、唯一主人及完整 WuxingCraft（精炼/温养/淬灵等）保留；另覆盖不同主人合并、无主左侧吞有主右侧、非主人命名拒绝，并断言失败不消耗两侧物品或经验。
