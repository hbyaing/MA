# 阵法刻画核心 · 流程预览

本轮按用户要求只交付工作台预览，未注册游戏物品/方块，未更改存档或供能结算代码。

用户确认：首批聚灵阵、防护阵、禁法结界；诛仙剑阵保留原入口。灵石费用和允许档位稍后设置，默认0费用/无允许档位代表规则未配置，不能供能也不扣石。

统一总入口：上级“启动全部工作台.py --open 阵法刻画”。选择阵法→5秒演示刻画→中心生成阵眼示意→勾选临时测试档位并填写临时费用→放入演示灵石→驱动。测试灵石采用现有1/9/81/729价值比；演示余额耗尽即关闭。临时参数不写入正式配置。点击“仅看阵法外观”调用已存在的原预览，明确标注不代表已供能；关闭外观或停机后卸载子页，停止后台绘制。

UI中央为核心/阵眼位置示意，不是最终游戏模型。核心是否被阵眼替换、实际阵法功效和最终参数仍需确认。本轮验证选择/刻画锁定、阵眼生成、未配置不驱动、档位限制、放入价值、驱动与耗尽关闭、重置和响应布局；详情见validation.json。
