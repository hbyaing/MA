玩法建议 · 可讨论版本

01 / 草药取消阶级年份与物种基础药性独立记录。药龄连续成长，不再跨黄玄地天仙档。

02 / X 是参数组灵性、生机、体魄、神魂、寒热、清净、毒性等参与反应；环境修正只作用于对应分量。

03 / 融合先于评分相生、相制、制毒与投药顺序先转化有限药性，再计算最终参数；不会把毒性当成加分项。

04 / 九品统一分档草案评分：48%有效药力 + 28%纯净 + 24%稳定 − 22%毒性。10 分起一品，每 10 分一档，90 分起九品。

05 / 药效由数值决定药性方向决定类型，药力决定幅度，稳定决定持续，毒性决定副作用。数量主要增加产量，不直接抬高品级。

06 / 失败单独处理空炉、低纯度、严重失稳或评分不足会失败，不能强行落入一品。工作台没有随机重掷。
