# 丹道重塑 · 年份与九品参数工作台

仅为 UI 和玩法试算，不修改游戏 Java、草药/丹药注册、配方、NBT 或存档，不构建或安装新游戏 JAR。

从统一入口启动：`python docs/previews/启动全部工作台.py --open 炼丹重塑 --no-browser`。

## 可交互内容

16 种示例草药，八个投药槽。草药无阶级，调整 1–10000 年和每槽 1–8 株；这是工作台输入范围，不是游戏药龄上限的决定。环境灵气、温度、湿度、月华、异火倾向、火候和时长联动；有水火调和、清净制毒、投药顺序示例。连续药效、1–9 品区间、失败门槛、参数账本、六秒三阶段演示、恢复/失衡示例、配方 JSON 导入导出和本地保存。

现有游戏素材取自 `src/main/resources/assets/wuxingxiantu/textures/gui/alchemy_concept` 和药草/丹药贴图。草药基础数值、融合系数、评分权重、年份曲线、品级门槛和效果单位全部为新草案示例，不代表当前游戏数值，也未将所有 32 种灵植作为已平衡配置。

## 计算顺序

1. 物种基础向量 × 株数 × `1 + 0.45 log10(1 + 年份/10)`，先汇总药性。
2. 对有限药性池进行转化。水火调和消耗温阳/寒润池，清净制毒消耗清净；不反复遍历全部药材对获得无限相生收益。
3. 根据火候、时长、环境和异火修正萃取与药性方向；按用量归一化。加倍全部同配伍用量不提高品级，主要改变产量。
4. 主导有效药性决定类型；选择目标只显示适配度，不强制变成指定丹药。
5. 草案评分 `0.48药力 + 0.28纯净 + 0.24稳定 - 0.22毒性`。分数限制在 0–100；10–20 为一品，依次递增，90–100 为九品。评分低于10、纯净低于25或稳定低于25则失败，不产生一品保底。
6. 效果强度读取最终主导药性、纯净与毒性；时长读取稳定；不直接以品级查固定效果倍率。
