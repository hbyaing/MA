# 紫曜背轮 · 可调色工作台 v2

打开 index.html 即可离线使用；全部着色器和脚本已内嵌，无外部依赖。effect.glsl 与 workbench.js 是可编辑源文件，修改后需同步 index.html 内嵌内容。

## 可调项目

- 六路颜色：法轮、符文、光脉、电弧、中心光雾和背景，支持颜色选择器与 #RRGGBB。
- 五种预设：紫红、青金、赤焰、冰蓝、幽紫。
- 十三项连续参数：亮度、密度、侧转、大小、符文速度、流动速度、电弧速度、粗细、长度、脉冲、展开时长、发光增益、总速度。
- 图层独立开关：法轮、符文、光脉、电弧和人物比例参照。
- 暂停/继续、重播展开、循环展开、时间轴、拖动侧转、滚轮缩放。
- 自动保存至浏览器；导入/导出 lucifer-halo/1 JSON；保存当前 PNG。

导入数据先验证再整体应用；超出范围或格式错误会保留原参数。导入只读取已知字段，不执行参数文件中的代码。

## 总入口

统一通过上级目录的“启动全部工作台.py”打开，可附加 --catalog 接入本机原有工作台总目录。旧记录 C:/Users/33140 的路径在本机不存在，兼容入口通过 --catalog 使用实际找到的原总目录，不修改原目录文件。

```powershell
python ../启动全部工作台.py --open 紫曜背轮
```
