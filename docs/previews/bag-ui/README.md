# 储物袋UI预览工作台

对应 ebb21b3 / 默认分支 c2cbc61 的原版墨金青玉风格恢复。按 BagScreen 和 BagMenu 的300×242坐标绘制，采用实际模组物品与正式磁铁开关贴图。网页字体和透明混合不等同于Minecraft实际渲染。

通过上级“启动全部工作台.py --open 储物袋”启动。支持缩放、环境背景切换、示例物品、名称筛选、分类轮换、整理演示、滚轮/拖动滚动条和磁铁开关，PNG导出包含搜索和按钮文字。不写入游戏数据。

Chrome已检查页面执行、资源加载、搜索筛选、磁铁切换与清空，截图检查边框/标题/按钮布局。只属于网页预览，未执行游戏实机验收。
