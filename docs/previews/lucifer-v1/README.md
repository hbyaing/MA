# 路西法背轮预览 v1

观察参考：41.31秒录屏，先每5秒采样，再检查6–9秒连续帧与第9秒完整画面。主要还原战斗中持续出现的紫红法轮：同心反转符文环、径向折线光脉、外缘电弧和脉冲；开场实体羽翼未纳入此版本。

原创解析式 GLSL 程序动画，未复制视频资产，也未上传参考录屏。中央为悬浮人物比例占位，不是角色模型。侧转控件压缩平面，不代表完整三维体积。

index.html：WebGL2交互预览，双击即可打开，无外部依赖；暂停、重播、亮度、光脉密度和侧转。
preview.mp4：1280×720，24fps，10秒，同一GLSL离屏渲染240帧，H.264编码。
preview.png：第6秒静帧；effect.glsl：共享着色器源码。

验证：桌面OpenGL3.3编译和240帧渲染通过，MP4编码通过。WebGL2浏览器兼容和Minecraft接入尚未实测。仅视觉第一版，不表示原视频完整复刻或游戏效果验收。
