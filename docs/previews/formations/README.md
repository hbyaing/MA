# 阵法统一工作台

整合已有聚灵阵、防护阵、禁法结界、诛仙剑阵常驻/展开动画、九霄剑诀、万剑归宗和紫曜背轮，共8个入口。保留原动画、配色和参数；每次只加载当前选中页面。

通过上级“启动全部工作台.py --open 阵法总”启动，不能直接使用静态文件服务替代：诛仙剑阵的实体四剑和展开动画依赖本机GPU。WebGL2可用时聚灵/防护/禁法/御剑使用浏览器绘制；GPU兼容后端与网页同源，不依赖旧固定端口。

## 环境

Python需要numpy、Pillow、moderngl、glfw；Node.js用于复用九霄剑幕轨迹。可通过XIANTU_GPU_DEPS指定本机额外Python模块路径。当前机器使用既有work/gl-check-deps，不将依赖打包进仓库。仅监听127.0.0.1，渲染参数沿用原界限验证。网页请求并发处理，GPU绘制串行在同一线程维护上下文。

## 操作

左侧搜索和切换阵法；各页继续保留调参面板。统一三维预览的左键拖动、滚轮缩放、双击复位；灵敏度按窗口大小归一化，支持指针取消、失焦、丢失捕获清理；松手无惯性。紫曜背轮为平面雾光，保留原平面侧转方式。

## 验证

Chrome逐页验证8个入口实际出图；展开页验证旋转、松手停止、缩放、双击恢复；分类搜索通过，未发现页面脚本异常。详见validation.json。修复了窗口切换时连接中断处理及网页/GPU请求互相阻塞的问题。

只整合预览和交互，不修改游戏代码，不代表Minecraft实机或外部光影验收。实体模型只打包预览消费的elements几何和独立贴图，去除Blockbench内嵌图片等编辑器负载；原始模型工程仍保留原路径及仓库来源。
