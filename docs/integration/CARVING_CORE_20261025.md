# 阵法刻画核心与灵石阵眼

## 使用流程

创造物品栏“万界仙途·阵道”新增阵法刻画核心：wuxingxiantu:formation_carving_core。放置时自动打开UI，之后可右键重开。首批选择聚灵阵、防护阵、禁法结界，点击确认刻画后核心原位转化为对应阵眼；已转化位置不能重复刻画。刻画动作直接完成，没有额外材料或时长规则；目前未新增生存合成配方。

手持灵石右键阵眼放入，潜行右键打开4槽供能界面。配置有效且有允许的灵石后自动驱动，可以暂停/恢复。只接受现有四档灵石，价值沿用1/9/81/729；不从玩家背包后台扣费。燃料不足关闭，补充后恢复；区块卸载时暂停，不强制加载区块。阵位绑定方块坐标，不跟随玩家。

聚灵阵通过既有onArray修炼加成入口生效，不建立独立修为账户或叠加同类倍率。防护阵与禁法结界本轮仅完成供能与基础着色器视觉，未实现未确认的防御数值/技能封禁机制。诛仙剑阵仍走原四剑和剑图入口。

## 供能配置（用户确认费用/档位稍后设置）

世界serverconfig/wuxingxiantu-carved-formations-server.toml：

```toml
[carvedFormations]
gatheringCostPerMinute = 0
protectiveCostPerMinute = 0
sealingCostPerMinute = 0
allowedStoneGradeMask = 0
radius = 5.2
```

费用单位为下品等值/1200个已加载服务端游戏刻。0费用或0档位掩码表示“规则未配置”，不驱动、不消耗。档位位值：下品1、中品2、上品4、极品8，允许多个档位时相加。未擅自确定正式费用。

灵石余能采用1200分之一价值单位的整数记账，预检总值后再扣石，避免不足时吞掉半份材料；同一tick重复更新不重复扣费。剩余未使用石头在拆除时掉落；已经转化但未耗尽的余能写入掉落核心的BlockEntityTag，重新放置/刻画后保留。保存重载保留燃料、档位、余能和暂停状态。

客户端与服务端须使用匹配版本，网络版本96。UI复用现有墨金控件与临时分辨率适配，关闭时恢复GUI缩放。实体核心使用石台/青玉材料小模型，运行法阵为本轮基础GLSL阵纹与半透明穹顶，尚未对照完整预览做实机视觉验收。
