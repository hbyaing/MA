# V5 旧数据迁移审阅方案（未执行）

## 推荐保值原则

1. 所有现存物品 ID 保留。旧丹保留原字段、数量、用途和实际服药效果，以 legacy 只读分支读取；新批次完成后使用独立 V5 schema 的九品和冻结能力规格。新丹只显示九品，不叠加旧五丹阶/四成色。
2. 未批准具体折算前，不将旧极品直接变成九品，也不压低旧丹效果、吞物、重置药龄或删除知识。保留原始NBT用于回滚。旧药材的药阶字段未来仅停止参与 V5 计算，年份/物种/炮制数据保留。
3. 后续先采集四成色×五丹阶、未分阶旧丹、特殊丹、旧ID和堆叠样本，列出原效果、成本、建议九品/冻结能力及收益差异，再请求具体转换批准。
4. 既有丹方知识可映射合理基础知识，不赠送全部高阶概念、实践技艺和研究认证。死亡/登录/两次迁移结果须相同。
5. 正在炼制的旧批次按其原规则结算；不能热切换到半套 V5。已成丹效果冻结，规则更新不静默重算。

本方案是可审阅的保值路线，不是已经实施的迁移。尚需决定：是否永久保留 legacy 丹药使用，或在映射审阅通过后提供显式、有备份的转换入口。此决定不阻塞独立引擎和面板准备工作。
