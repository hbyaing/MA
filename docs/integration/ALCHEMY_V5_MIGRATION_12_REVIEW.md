# 第 12 项：旧丹统一迁入 V5（开发中）

2026-10-29 用户决定：旧丹药全部迁入 V5，删除阶级，统一使用一至九品。此前保留旧丹原效的并行方案已经撤销。

## 当前实现

- 旧丹进入玩家物品栏或使用时，由服务端一次性转换。未加载箱子的旧丹在取出时转换，不进行全世界离线扫描。
- 数量和无关 NBT 保留，原始序列化数据归档。旧成色、药阶、元素及修为类型仅用于确定导入结果，转换后不再作为活动品质字段。
- 导入结果固定，不补造历史炼制过程，不反复随机，不授予炼丹职业认证。品质根据转换后冻结参数计算为一至九品。
- 新丹仍由实际材料、药龄、工艺和环境生成。扩展材料、效果模块、研究模板与澄清工序已加入源码。
- 后台客户端验收代码仅在显式测试构建启用，使用独立存档与禁止鼠标捕获的测试入口。

## 本次上传的验证边界

这是按用户要求提前上传的源码检查点，不是第 12 项完成交付。前一轮服务端回归 471 项通过，随后增加真实九品工序和兽血批次测试。最近一轮全量回归暴露研究公开规则上限问题，源码已将对应预算从 64 调整到 128，尚需重新跑完整回归。

参考矩阵已跑通 13,824 组材料与工艺组合、680 组旧丹参数组合，但不代表全部玩家玩法和兼容性已经验收。独立客户端迁移、重启持久化、界面截图复核、正式 JAR 安装尚未完成。第 13 项兼容与压力验证未开始。
