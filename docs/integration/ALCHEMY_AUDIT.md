# 炼丹融合核对（第6项，2026-10-21）

主框架仍为五行炼丹、知识和唯一职业账户；D03–D14、D30按既有确认方案核对，没有新建来源独立丹道等级或改价。旧UI继续交付，新四阶段UI留在独立分支。

| 项目 | 权威入口 | 本轮结论 |
|---|---|---|
| 丹方 | AlchemyRecipe、FormulaKnowledge | 静态核对140条alchemy配方；25条新增分阶配方为5种丹药×5丹阶；配方材料数/正数量/阶与成色字段检查通过，清单见alchemy-recipe-audit-20261021.json |
| 丹阶与成色 | MedicineTier、PillData、AlchemyGradeOdds | 黄玄地天仙五丹阶独立于下中上极品四成色；旧配方兼容，不能把药龄、六炉阶、异火等级当成同一轴 |
| 知识与职业 | FormulaKnowledge、PlayerCrafts | 丹方按玩家保存，同方覆盖不同结果档；炼丹职业只用alchemy账户；四档传承卷轴有限补经验，不授代表作、不自动晋升，份额按当前职业阶共享并保存 |
| 典籍 | KnowledgeItems、MyriadCompendiumItem | 万界仙典使用现有书阅读入口，按知识与职业状态生成；界面展示仍归第12项实机验收 |
| 普通炉副药 | AuxiliaryAlchemy.allocate、AlchemyFurnaceBlockEntity.reserve | 只查前8素材槽的未被配方占用槽；每类取首个足龄副药槽，每类恰扣一株，剩余堆叠不用于额外收益 |
| 天地为炉副药 | HeavenlyFurnace.start、AuxiliaryAlchemy.allocate显式重载 | 只使用明确选择的三个角色槽；错角色/主药已占用/重复/越界/无龄选择拒绝，不扫描未选择背包草药 |
| 副药结算 | AuxiliaryAlchemy.Plan、finish | 快照保存已付副药的药龄/NBT；成功产物附副药计划，重复finish不重复加产量；失败产物没有免费副药效果 |
| 服药 | AuxiliaryAlchemyEffects、MedicineProgress | 主丹成功且主框架资格通过后才附加效果；恢复走现有药力账户，不覆盖更强buff；近战效果保护宠物/中立/仆从，排除远程与过期状态 |

## D30副药角色

- 成率类：星辰草、天机花、金刚草。
- 药效类：幻灵草、寒冰草、烈阳花、毒鸩草、风息草、百年灵芝、雷藤、岩甲花。
- 产量类：丰灵草、灵稻。
- 其余来源草药仍作为主药等用途；不会把18种全部强行赋予副药角色。一次最多每类一株，配方要求的引药不能重复计作副药。

## 取消、失败与退款边界

| 路径 | 材料 | 灵力 | 重复结算保护 |
|---|---|---|---|
| 普通丹炉取消/结构或异火失效 | 材料留在炉内，释放预留 | CraftingJobs按该任务入退款账户，登录/在线按容量分批补回 | 任务移除、requestId与炉中状态校验 |
| 普通丹炉实际失败 | 消耗配方预留及每类一株副药，产生丹灰/废丹 | 炼制成本保留 | 失败结果保存，不能再complete或failExperiment |
| 天地为炉取消/中断/登录恢复 | 返还已托管的原始材料/NBT；背包满则掉落 | 已消耗施法灵力不返还 | 先删除ESCROW与RUNNING，再发还；旧token不能重放 |
| 天地为炉完成 | 不返主药/副药，只给已保存的结果 | 已消耗施法灵力不返还 | 完成先清托管与运行状态，再发结果 |

本轮新增IntegrationAlchemyGameTests三项：真实天地为炉请求的无效选择原子拒绝、每类单株扣费/未选材料保持/重放拒绝与带NBT取消；满背包原始托管物的准确掉落及二次取消；普通丹炉失败前后保存、单株副药结算与失败结果防二次领取。

退款不承诺回到原背包槽位，只要求物品身份、数量、药龄、炮制与其他NBT守恒；失败请求则要求原槽位和状态完全不变。
