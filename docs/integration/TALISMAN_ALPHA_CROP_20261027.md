# 符箓工作台框外像素透明化

用户重启后的实机反馈仍能看到框外底色。此前只在默认窗口绘制时使用几何裁剪，共享 PNG 的框外区域依然完全不透明，放大模式也复用了未裁剪的 frame 素材。本次直接修复三张共享贴图，并让透明混合覆盖共同绘制入口。

- background.png、engrave_background.png、frame.png 分别清除 85,225 个框外不透明像素。沿原有金框轮廓逐行取边界，四边与四个斜角以外 alpha 全为 0；框内 RGBA 逐像素保持不变，不重新采样、不改变布局和物品栏行数。
- 使用常规 GuiGraphics 绘制透明素材，移除默认窗口专属的自定义 GPU 网格；统一为真实的 1408×1117 纹理尺寸，放大模式的九宫格采样同步修正。
- 新增透明边缘资源检查，正式 build 及 verifyFull 均会执行，防止替换素材时重新带入不透明留边。原图逐文件校验后备份至 E:/垃圾，处理脚本保留。
- AGENTS.md 记录由助手自行核查实例、运行时间、实际加载包与日志，验收结束关闭多余测试实例，保留用户正在使用的游戏。
