# JEI 避让与统一灵脉矿石

背包界面的 Forge 几何信息使用整窗边界，但原版状态效果绘制使用物品栏的内部位置。JEI 15.59 的 InventoryEffectRendererGuiHandler 用整窗右边界推算状态效果栏，导致实际空白区域也被避让。

可选 JEI mixin 只修正 CultivationMainScreen 的这一个原版效果处理器，使用实际内部坐标；识海等不绘制原版效果栏的页面不再产生该效果避让。整窗边界、其他模组附加区域和原版背包均保留。尊重 JEI 关闭状态效果避让的配置。未改界面素材。

灵脉新区块统一生成 spirit_vein_ore，数量、洞壁连通与灵气场规则保留。矿石不再按生成时的品级分为四种；采掘时按基础权重 60/25/10/5 随机选择下/中/上/极品灵石，时运增加选中品级的数量，精准采集得到统一矿石。规模五也遵守同一随机掉落规则。

旧三种矿石注册保留，以兼容存档里的方块和物品；从创造目录及 JEI 列表隐藏。旧方块使用同一掉落表，精准采集后统一为普通灵脉矿石。不会主动扫描或重写已有区块，旧库存矿石可正常放置采掘转换。

服务端回归覆盖四种注册矿石各 2,000 次普通采掘、2,000 次时运采掘和精准采集，检查四品分布、仅选择一个品级和旧矿转换。客户端专用验收覆盖配置 GUI 缩放 1/2/3、背包/识海、有无状态效果共 12 种情况，调用真实 JEI 处理器并截图，同时确认 JEI 列表只显示统一矿石。专用鼠标保护与测试代码不进入正式包。

验证：verifyFull 通过（340 个必测，含新增掉落表测试）；客户端 12 个用例全部通过，failures 为空。GUI 配置档位 1/2/3 在 1600×1000 下实际缩放为 1/2/2，符合现有背包自动适配规则。鼠标保护检查 1,547 帧、0 次捕获违规。报告与截图位于本地 reports/jei-layout-20261025，完整服务端日志位于 reports/jei-ore-full.log。已目视检查背包与内视的整窗截图，JEI 列表不再为窗口外虚构的状态效果栏留空。

项目仍为开发进度快照；本轮不代表客户端光影、全部自然生成或完整存档重载的整体完成验收。
