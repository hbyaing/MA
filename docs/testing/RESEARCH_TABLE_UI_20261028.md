## 基础交互与服务端边界

- 基础观察保留样本，需现有炼丹入门资格；服务端执行时实时查询FormulaKnowledge，不信任旧菜单同步标志。
- V5样本核对真实已领取批次与公开结果；未知/伪造批次拒绝。旧制物品只核对已有公开数据，不伪造其原始V5轨迹。
- 仅展示已公开的冻结药效、品级等信息，不发送种子、原始投料、隐藏过程或规则快照。完整知识裁剪/深层痕迹留09–10。
- 保存个人记录消耗纸与墨囊各1，保留样本；重复记录不扣费。V5以批次指纹去重，旧物品指纹排除显示名/修理费用。64条上限，摘要有界，最新摘要以有限菜单数据同步，中文按UTF16正确传输。
- 记录接入FormulaKnowledge既有玩家持久化与克隆流程，不增加职业、修为、经验或认证，不作为独立复验证据。
- 换样本清除旧观察；伪造视图状态、另一玩家操控旧菜单、知识撤销、远距离请求和耗材不足均不能保存。桌面容器按Minecraft保存/拆除掉落规则处理；任意断电的跨文件事务不在本UI验收范围。
