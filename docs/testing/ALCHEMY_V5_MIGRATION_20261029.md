# 第12项：统一迁移与目录覆盖（2026-10-29）

## 规则与范围

用户决定全部旧丹迁入V5，删除旧药阶与成色品质轴，统一显示一至九品。原始数据保留在服务端备份中，停止旧丹的活动效果结算分支。内丹仍是妖兽材料，不作为普通成丹删除；创造丹作为显式管理物品导入，普通炼制策略不能生成其管理能力。

生产版本：网络协议105，输入schema2，反应规则`furnace-catalog-5`，正常能力策略`v5-effects/2`，旧丹导入`legacy-import/1`及`v5-import/1`。旧批次继续使用自己的冻结规则与策略，不追溯更换。

## 一次性导入

- 服务端每秒至多处理4个库存堆叠，手动使用会先迁移。未加载箱子等容器不离线扫描，在取入物品栏或使用时转换。创造栏收敛为每种用途一个源模板，灵根元素和修为境界保留必要变体。

- 在注册表查找前封存旧ID序列化数据；每次导入先保存槽位意图、固定UUID、原始数据与策略，再写独立导入权威记录，替换库存并保存玩家，确认磁盘库存含同一UUID后关闭意图。原始数据含无关NBT及未知能力归档，活动物品删除旧Grade、MedicineTier、Element、CultivationTier字段。

- 原数量不变，导入后效果冻结，重复加载不随机、不重算、不补发。数量变化和真实服用使用同一服务端剂数凭证；不能复制耗尽的堆叠重新取得药效。旧数据缺失真实投料和环境，导入不伪造反应过程、实践证据或职业认证。

- 非法旧字段、超预算效果集或持久化确认失败保留原物或意图并记录原因；没有静默吞物或无条件重新估值。已学丹方保留，只映射可解释的基础观察理解，原始知识归档，不赠送高阶概念与认证。

- 药效不能宣称与旧百分比系统逐点相等：回血按40生命、回灵按100灵力参考值计算并冻结，修为与凝元按原境界容量和上限确定；旧药阶/成色仅在首次导入计算中读取。付费副药与兽血附效转为有限白名单规格，同类规格合并而非重复奖励。灵根、洗髓、突破、渡劫、拓脉等继续遵守既有资格和次数限制。

## 全目录与真实物理

32种药材在0、100、1500、6500与年份上限、原料/炮制状态逐项适配。140张既有配方涉及15种非草药材料，现均显式登记；普通惰性材料不凭空获得活性，兽血按实际来源强度提供有限活性，未知材料拒绝。兽血来源批次也在储物袋合并/取出时保存，强度是反推显式变量，不能把不同强度误当同路线。

6种设备和9种异火来自实际生产定义。38种普通能力、95条公开规则与26个部分约束模板覆盖22种丹药用途和五行灵根变体。模板只声明已理解的局部约束，不承诺投入旧配方必定产出旧名称、旧品质或全部复合效果。

萃取共享能量时降低单条规则抢占上限；融合结构必须消耗真实提取物。新增低温澄清窗口会将未提取原料变为惰性残料并丢失其潜力，不新增物质、潜力或能力。4份1500年回春草、基础炉和赤炎流火可在萃取后通过3次真实控温转为停火，满足澄清后得到九品；持续加热不能代替这一步。

## 验证边界

服务端参考矩阵13,824组：32物种×3药龄×3数量×2炮制×6设备×2异火×2控温策略。每组记录终态、数量、品数和质量守恒；另有真实扣料/预付/控温/领取和旧丹服用测试。矩阵是固定采样条件，不能当作玩家成功概率、全目录最优路线或多人实机吞吐量。

第13项仍保留：完整自然昼夜、多人并发、JEI有无、外部光影、极端故障和任意回滚组合。当前实现不保证任意断电、损坏存档或跨文件任意回滚都能恢复。最终测试、客户端与包安装记录见本目录证据和第12项交付记录。

旧聚气丹的导入持续时间可达14,400 tick，公共回灵计时器现接受导入规格允许的有限窗口（最高72,000 tick），避免下一次计时或登录检查提前删除合法药效；普通炼制策略仍限制为12,000 tick。新增真实服用与登录复核测试。

管理用创造丹的可受益检查复用原服务；满配与灵力充足时拒绝消费。原满配判断把已转入剑术账户的五种剑术仍当普通功法查询，现按既有剑术学习记录检查，避免永远判定未满配，不新增学习账户。

满配检查同时只要求仍在正式白名单中的变形形态；历史列表残留的九种已删除玩偶不再造成永久未满配判断，不恢复这些已删除实体。
