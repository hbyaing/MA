# 炼丹 V5 第 08 项：多入口统一结算（2026-10-28）

## 入口与行为

| 入口 | 投入与设备适配 | 结算 |
|---|---|---|
| 普通炉自由配伍 | 原八槽实际药材、异火瓶、炉档/磨损、预付炉内燃料和蕴月瓶 | V5Batch → BatchIncidents → PillSnapshot → BatchDelivery |
| 普通炉固定丹方 | 校验丹方知识、境界、异火、炉档和匹配材料；按配方数量扣主药，剩余槽每类副药一株；未预留材料留在原槽并锁定 | 同一反应核心、药效编译、九品和耐久领取；不再随机抽旧四成色、额外成功率、产量或兽材/副药词条 |
| 天地为炉炼丹 | 既有神通/丹方/火种资格及空间检查；显式选择副药，背包最多36个来源槽；按所选丹方的炉档绑定虚拟设备容量与供热，境界决定可用上限 | 同一核心/事故/冻结策略/剂数凭证；聚材12秒后每20加载tick推进一步；输出由同一 BatchDelivery 发放 |
| 天地为炉炼器 | 原有资格、器方、认主继承与费用 | 保留炼器原流程，本项不改成炼丹模拟 |

固定丹方图标是旧方例，不承诺复制旧丹种、旧品质或旧能力。真实投入会决定当前九类模块中的实际药效。例如回灵方例可能因真实药性产生治疗模块；不以预览图强制生成旧结果。完整丹方知识与目标约束归09，全量材料能力/平衡归12。

## 有限材料与副药

- 已定义药材沿用第04项的物种、年份、炮制和属性适配，不改旧批次规则或第07项编译算法。
- 非药材的固定方原料（例如红石）以 `massPerItem × 数量` 进入 `herb_inert`：保留质量，不虚构有益药性、效果预算或特殊词条。自由配伍仍拒绝未知药材。
- 副药与主药一起形成实际库存；旧副药分类仅用于现有选择槽，名称不再保证成功率或产量加成。旧丹附带的既有副药效果继续兼容；尚未注册的冰火毒附击不伪装为新白名单能力。
- 天地为炉的已装备异火是既有角色火种资格的设备适配，不生成额外可领取的异火瓶。蕴月瓶最多一个、释放上限1000；原瓶及未释放月华在同一次玩家保存中回到原背包槽，不丢瓶、不重复释放。

## 事务与恢复

普通炉沿用既有按位置索引的权威批次事务。天地为炉新增同一世界日志下的 `portable/<owner>.nbt` 索引，指向同一 `batches/<id>.nbt`。它参与既有玩家炼丹活动上限，不新增职业、货币或角色账户。

天地为炉开始顺序：完整预检 → 写入含原槽完整NBT/扣量/费用/核心和规则快照的批次 → 写玩家索引 → 扣料和既有灵力、写玩家消费凭证 → 保存玩家 → 从实际 player.dat 回读凭证 → 批次标记 InputCommitted。确认前不推进反应或领取。写入失败保留日志；凭证已保存的确认重试不重复扣料，未支付且原槽已变更则停止并保留记录，不拿替代物品顶账。凭证只保留当前批次一条，避免无限累积。

实际扣费保留原天地为炉服务费计算，并至少覆盖本批次预留燃料；创造模式保留免玩家灵力规则，实际材料仍托管。普通炉不额外重复扣玩家灵力。封存后未用的炉内预留量仍留在燃料账中；天地为炉已扣神通费用不返还，不把虚拟设备余额返成可刷玩家灵力。

- 满背包：结果留在权威记录，腾出空位后一次发放，不丢地、不退原料、不重新生成结果。
- 断线/正常停服：保留同一批次，登录后按原规则/种子恢复，无离线反应或燃料追赶；实际加载间断仍走06的连续性损伤。
- 主动收束、离开施法范围、失去资格或死亡：V5不可逆中止，结算有限药渣/废丹；不返还已入反应的原始材料。死者结果保留，活着且有空间后领取。
- 已有旧 ESCROW/CraftingJobs/封存批次按原记录兼容结算；不再创建新的旧随机炼丹任务。旧丹及旧物品价值未迁移。
- 外部修改玩家存档、任意操作系统断电以及全部并发故障组合仍归13，不宣称跨文件数据库原子事务。

## 界面与版本

复用原按钮、美术和布局，只更正语义：两种普通炉模式均显示真实批次结算、预付额度、服务端工序时长与警兆；固定模式同样能调火、温养、泄压、封存。移除旧四成色概率与异火吸收预计增量。天地为炉目录显示按实际反应结算，副药提示明确不保证增益；神通说明区分炼丹中止与炼器返材。

网络协议100；核心 `alchemy-core/0.1.0`、规则 `furnace-effects-3`、效果编译 `v5-effects/1` 未改。批次增加 Entry/Recipe 入口元数据；旧无Entry记录维持实体炉路径。服务端内部 PlayerInputs、付款凭证、策略、原料完整NBT、种子和操作历史不进入公开成丹manifest；神通广播只使用原有视觉壳，不发送批次私有记录。
