# 第10项：对照、有限观测反推、双难度与研究谱系

基于main的09基础链路。沿用已批准研析台V2与统一FormulaKnowledge/PlayerCrafts账户，协议103。实际炼制、资源预算、事故、药效与品级继续由原V5引擎决定。

## 实际游戏流程

1. 通过已有传承研习配伍、火候，完成真实炼制。在鉴定页观察合法V5成丹，再进入反推页“研习研究法”。该研习不授予控火经验或药力。
2. “实验”页选择本人批次作对照基准，翻页选择另一批，点击比较。相同条件、单因素差异、多因素混杂、同批次自比较、版本不同分别提示。两批不直接证明因果或统计独立。
3. “反推候选”以样本的公开药效目标筛选本人已有实验路线。保留等价路线和矛盾记录；只排除已测的不符点，不排除未知材料组合，也不读取目标的原始配方。结果目标要求模块、最低强度/时长、触发间隔、冷却、境界要求与毒性边界，丹药品级和产量不充当难度或配方承诺。
4. 候选的五张卡：概览及研究歧义、药龄假设、用量假设、声明范围、操作剖面。药龄按钮降低当前首个可编辑原料的20%（至少1年），用量按钮减少当前首个可减原料1件；卡片显示具体原料，悬停可查看完整原料。另可扩展首个正药龄声明区间上下20%，或恢复观测方案。这些是便捷提案步长，不是通用降级许可或可靠性阈值；不修改实物或自动执行炼制。
5. 纸墨各1保存一个新的候选版本，重复同内容不扣费。谱系页可选父方或第二父源，下一次保存形成分支/合并；不创建修改旧祖方的入口。改回祖方后净偏移可为0，累计路径仍保留。版本上限32，研究数据总预算1MiB。

## 证据与隐私

- 新V5批次增加服务端`ResearchStart`：开炉环境和时刻。`ResearchControls`记录实际接受的玩家控制指令，最多512条，超限标记不完整；不阻断原物理操作。主动封存另标记干预。旧批次不补造初始环境，仍可领取/服用/查看旧实践摘要，但不能冒充完整对照证据。
- 以本人权威已结算批次重建材料身份、炮制、用量、药龄、开炉环境、实际环境变化、火种特征、设备、储备灵力、中断和操作干预。只读本人前128条实践索引，缺失/旧记录明确计入未覆盖数量。可交易样本只提供公开目标，不提供原作者的投料或操作。
- 比较干预而非内生结果：事故提前结束不当成玩家改工序，自动泄压的资源量不当成额外配方变量。实际外界变化/未受控中断仍可能使一组对照不合格。保守拒绝不等于证明物理不可行。
- 研究只向客户端发送当前页授权文本/摘要；没有原始种子、随机流、隐藏规则或全知原方包。每栏文本上限640字，实机面板分卡与悬停查看。服务器重新校验真实菜单/操作者/距离/存活/知识/当前动作/实际鉴定样本/纸墨；不信任可见按钮标志。

## 有限求解与独立难度

`ResearchInference`只有公开目标与授权观测输入，不接触V5引擎求解器或目标私有日志。同一完整条件与规则上下文分组；存在达标观测则保留路线，组内所有不符/失败仍保留。无支持的已测点被排除，未测点保持未知。最多展示32个候选，溢出数量计入未覆盖。它不是对整个药材目录的穷举或凭一颗丹恢复唯一原方。

研究剖面独立报告候选路线数、矛盾路线、可区分的单因素对照与缺失记录，不伪造置信度百分比。难度中的“易/难”以歧义及证据缺口解释，不从品级推算。

操作剖面只用明确研习过的公开模型：`alchemy/research-methods.json`登记当前33条基础提取规则；学习绑定每条规则内容哈希。规则改变后不按同名自动继承知识。只计算已知、可由本人实际材料达到的公开反应路径，隐藏工序仅显示模型不完整。显示实际窗口数量、连续保持步数、温窗跨度、设备最小非零加热档能量及控制噪声。温窗端点差的保守能量跨度小于单步加热响应与噪声带时提示精细控火（不把整数测量边缘余量当作额外容差），连续保持超过当前阶段计划预算则指出时长不足；阶段预算包括真实操作中付费温养的已观测延长；不是自动推断整条路线绝无其它解，也不把最大供热速率误当最小分辨率。改方后的实际操作表现需新实验。

当前正式数据主要是宽约束基础提取；四类研究/操作难度组合由独立规则夹具覆盖，不能宣称已新增四种完整特殊丹。模型和上下文在研究菜单打开时固定，重开读取新资源；保存时再次对照当前规则并标记旧语境需复验。

## 不可变谱系与有效域

世界唯一职业账户的alchemy行保存`ResearchRevisions`，每个版本有服务器作者UUID、内容ID、formula/root/parents（最多2个直接父源）、所有根源、原始基准、目标、方案、声明域、证据与引擎/规则/输入/能力语境。节点只追加，父源必须已存在于本人授权图中，因此新节点不可能指向未来节点或形成环。没有客户端自报“已认证”的导入入口；尚未提供跨玩家共享或文件导入/导出界面。

数值坐标保留原单位：年、件、能量/设备量等，不混成任意总分；离散材料/炮制、工序、环境轨迹、火种改变单列。每个数值轴保存相对首根的绝对净变化与逐代绝对路径和，合并时保留每条父链的最大路径包络，避免重复计入共有祖先，也不洗掉第二父源。目标改动次数、规则漂移独立记录；偏移不进入物理公式，不扣药力、不禁止合法创新。

声明区间只是待证假设。`JointPoints`只保存实际同时观测过的完整坐标，不把各轴最小/最大拼成未测超矩形。同一批次只链接一次，保留范围内所有支持/不符记录；改药龄后没有该联合点便没有自身证据。祖方仅提供方向和仍适用的旧引用，不增加子版本独立样本。状态为候选/已有观测支持/矛盾/原规则需复验，均不等于11项正式独立验证或认证。
