# 闻声魔·耳魅

筑基期突破试炼 / 耳贼

## 模型与动画

`ermei.bbmodel` 是主要工程，采用 Bedrock Entity 格式，包含内嵌的 256×256 像素贴图。通过 Blockbench MCP 创建和检查，保留 21 个骨骼组。

无面人形以石灰骨白和暗青灰构成，旧铜色强调关节与耳廓。已移除耳廓中心的长方体人头，改为完全留空的螺旋共鸣腔，缩短收窄的颈部连接耳廓根部。胸口保留暗色心窍；肋部、颈部、前臂与胫骨的青色纹样表现身体作为共鸣腔。全高约 5 格。

动画轨道：

- `animation.ermei.idle`：3 秒待机，胸腔起伏、耳廓轻颤、双臂微摆。
- `animation.ermei.sonic_ripple`：3 秒循环，三层声波环依次扩大。此轨道是几何预览，环在周期边界重置。
- `animation.ermei.soundmark_vibration`：0.6 秒音纹脉动，可与待机同时播放。
- `animation.ermei.prelude_cast`：1.8 秒前奏施法，抬臂、耳廓后仰后回正。

`bedrock_source` 内包含骨骼模型、动画和半透明环形粒子源文件。真实粒子采用面向镜头的环形贴图，持续扩大并渐隐，外观与工程中的水平几何预览环有所不同。接入时可隐藏 `soundwave_preview` 组，并停用其几何动画。

## 验证与接入范围

已在 Blockbench 检查模型渲染和声波轨道的实际缩放，并验证贴图内嵌及动画骨骼引用。材质、动画和粒子尚未在 Minecraft 客户端中验证。

交付仅包含 Boss 美术源文件，不包含场景、完整实体行为、声音文件或 Boss 战逻辑。Java 版需根据实际使用的 GeckoLib、Model Engine 等目标适配，基岩版需补齐实体、资源包和行为绑定。
