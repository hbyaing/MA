2026-09-18 接缝修正：八片心镜统一按镜片局部坐标投射裂纹，修正正反面 UV 方向，解决不同宽度条带之间的横向错位；相邻条带的微小重叠改为共用边界。保留刻意设计的缺口、心轮位置、骨骼及全部动画。详见 `mirror_alignment_validation.json`。

最新调整：肩部、胸腔边缘、腰胯、手臂和大腿改为错位悬浮碎块，后脑改为七块大小与角度不同的残片。后颈至腰部增加五段黑紫镜质脊节与两块过渡残片，配合紫色纵向裂隙，强化背部中心。面部红缝加宽并增加猩红层次、中段亮色、收尖末端和少量分叉。黑色背板已删除，胸腔前后通透。八片心镜保留扩展的主裂隙、分叉细纹和边缘裂口。当前为 515 个立方体、71 个骨骼、12 组动画。

## 形态

本体约 3.5 格高，脚部残片位于地面以上约 8 个单位，即约 0.5 格。在保留原骨骼与动画的优化中，心轮外轮廓宽度缩小 11.96%、高度缩小 10.38%，整体约 4.7～4.8 格。八片镜面位置轻微错开并朝内倾斜，Z 轴中心为 6.9～14.8 单位，形成略有弧度的空间层次；镜片展开时轮廓进一步扩大。

黑镜头部没有常驻五官，中央为深红至猩红的纵向裂隙，中段较亮、两端收尖，少量分叉打破直线感。正面仍以近黑镜面为主，头部局部扩大 7.5%。新增红缝部分跟随原 `face_rift_seam` 骨骼，在开缝动画中同步缩退；两半镜面打开时短暂显露后方的像素眼睛幻影，随后闭合。后脑七块残片采用不等尺寸、错开的接缝与前后深度，保持原有头部轮廓，不形成皇冠。红缝专用 UV 区域已包含在发光遮罩内。

胸腔由侧壁、锁骨和底部残片围成真正的空洞，红色妄心独立悬浮其中。中央为错角拼接的暗红不规则魔核，外围有三块深红碎晶并保留空隙。亮红与紫红细裂纹集中在核心中心；外晕前后面不遮挡核心。整个妄心继续由原有 `heart_core` 驱动搏动、旋转、前移暴露，未来可在同一骨骼叠加浮动或快速搏动。四条细能量线属于视觉连接，不是实体支架。

右臂上臂与前臂采用较紧密的悬浮分块，保留人形手掌、握持结构和空骨骼 `weapon_anchor`。左臂由魔气、可散开的碎镜和三条各自独立的锁链构成异化魔爪。肩部、胸腔边缘、腰胯和大腿实体也已拆成错位碎块，保留人形走向；膝部和小腿逐渐稀疏，脚踝断开，足部仅剩残片。新增身体碎块继承原部位骨骼运动，没有新增逐块独立漂浮动画。背部为五段窄幅镜质脊节与两块过渡残片，纵向紫色裂隙沿后颈延伸到腰部，保留断开的空隙及肩胛分支。

八块心轮镜片各自拥有独立骨骼、位移与旋转能力。外形保留同源镜片结构，局部宽窄、单侧缺角和裂口形成轻微差异。镜面为极暗渐变和少量紫白裂纹，每片分配独立 64×64 UV 区域，区域表见 `mirror_material_regions.json`。发光遮罩只保留微量裂纹，其他区域可用于未来幻象；未将玩家、武器、六贼或三尸图案画入镜面。

## 骨骼与接入

文档要求的骨骼均已保留：`root`、`body`、`chest`、`head`、`face_mirror`、`heart_core`、`right_arm`、`right_forearm`、`right_hand`、`weapon_anchor`、`left_arm`、`left_forearm`、`left_claw`、`chain_1`～`chain_3`、`left_leg`、`right_leg`、`heart_wheel_root`、`mirror_1`～`mirror_8`。

`face_left` 与 `face_right` 控制镜首开合；`face_rift_seam` 在开缝时缩退，避免细缝遮挡眼睛。`left_forearm_shard_0`～`left_forearm_shard_4` 控制异化前臂解体。心轮八片是同一模型中的独立骨骼，若玩法要求独立受击实体，应由服务端另设相应实体或命中区域。

右手挂点用于附加物品渲染层；当前没有内置固定武器。将玩家武器的暗紫幻影版本渲染到 `weapon_anchor`，并在项目中校准物品旋转、缩放和握持偏移。不要直接按编辑器坐标推断运行时左右方向，应以导出骨骼和目标渲染器为准。

建议将悬浮、心核、心轮与技能分成不同控制器。技能接管 `heart_core` 或 `heart_wheel_root` 时暂停对应循环动作，结束后恢复默认姿态，避免多控制器同时覆盖同一骨骼。镜花水月朝向玩家的实时转向需要运行时计算；当前模型动画使用本地前向。光轮残影在静态模型中缩小为 1%，万念俱灰时展开。

主贴图包含半透明魔气，目标渲染器需要启用合适的透明材质。发光遮罩用于配置发光渲染层，并不自动产生世界照明。镜面采用极暗渐变；真正反射玩家、显示六贼三尸幻影、屏幕扭曲等效果需要 Shader 或专门渲染逻辑。八片镜面共用一张图集，但 UV 区域互不重叠，可独立更新对应区域或在渲染层中按骨骼处理。

## 检查结果

优化后为 515 个立方体，仍为 71 个骨骼、12 组动画。原骨骼 UUID、名称、父子层级与动画 UUID、名称全部保留。此前为适应心镜的新位置和倾斜，校正过原有格挡／展开动作的镜片位移与转向；本次身体、脊柱、红缝和后脑优化未修改动画内容。已检查正面、背面、左侧、右侧和 45 度视角，以及几何数值、必要骨骼、动画引用、内嵌贴图、镜首开缝、妄心暴露、前置巨镜、锁链前射和心轮展开姿态。工程使用 Blockbench Bedrock 实体格式作为共享几何编辑格式，导出的几何与动画资源整理在 Forge assets 目录中。

未在 Minecraft / Forge / GeckoLib 实机环境加载验证。实体注册、技能命中、动画控制器、物品复制、实时镜面和粒子逻辑不在本次模型交付范围内。
