# 贪味魔·舌饕

元婴期突破试炼 / 舌贼

## 最终外观

以巨舌作为视觉主体，肥胖人形作为承载巨舌的躯壳。巨舌从腹部大口深处伸出，先向前下方盘曲，再抬至接近躯壳顶部；宽厚舌缘、中央沟槽、凸起味蕾和悬垂黏液强化舌头的辨识度。舌体采用连续曲线排列的立方体体积，绑定 7 节舌段与 1 节舌尖骨骼。

灰青色水袋状躯壳约 3 格高、3 格宽。巨舌显著超出躯壳前方，完整外观与动画不能按 3×3×3 格封闭空间裁切。

共 14 张口器：腹部巨口 1、手心 2、脚底 2、肩部 2、侧腹 2、脊背 4、头顶 1。口器采用暗色喉腔、红色内壁与外唇、参差牙齿和流涎；腹口下颌可活动。

最终工程为 648 个立方体、49 个骨骼组，共用 256×256 像素贴图。

## 文件

- `shetao.bbmodel`：可编辑的 Blockbench 主工程，Bedrock Entity 格式，贴图内嵌。
- `shetao_atlas.png`：独立贴图。
- `shetao_preview.png`、`shetao_front.png`、`shetao_back.png`：整体预览。
- `shetao_soles.png`、`shetao_crown.png`：脚底与头顶口器检查视图。
- `bedrock_source/shetao.geo.json`：骨骼模型。
- `bedrock_source/shetao.animation.json`：五段动画。
- `bedrock_source/particles/shetao_food_crumbs.json`：持续掉落的褐色残渣粒子。
- `bedrock_source/textures/particle/shetao_crumb.png`：残渣像素贴图。

## 动画

| 动画 | 时长 | 表现 |
|---|---|---|
| `animation.shetao.idle` | 3 秒循环 | 肥胖躯壳起伏、双臂轻摆 |
| `animation.shetao.hungry_chew` | 1.2 秒循环 | 腹口下颌咀嚼，各小口错相伸缩 |
| `animation.shetao.tongue_core_writhe` | 4 秒循环 | 八节巨舌轻微蠕动 |
| `animation.shetao.tongue_lash` | 1.6 秒单次 | 巨舌蓄势后沿骨骼链向前甩击 |
| `animation.shetao.drool_and_crumbs` | 2 秒循环 | 腹口涎水拉长、几何残渣下落与重置 |

## 粒子与接入

粒子源文件按单个口器发射点设计，每秒 3 粒褐色残渣，受向下加速度影响。游戏内需要为各口器分别绑定发射点，腹部巨口可用多个发射点加强密度。发射后保持世界空间运动，确保背部、手心等朝向不同的口器，其残渣仍向地面下落。

`food_crumbs_preview` 是模型内的几何示意。接入真实粒子后可隐藏该组，并移除 `crumb_*` 动画轨道。粒子不会仅因加载模型而自动绑定；当前没有实体行为、伤害、吞食或掉落逻辑。
