# 设置开关第二版

用户明确要求先生图再提取。第一版八角滑块被否定，未实装。本轮第二版采用切角墨色槽、细哑金边框和圆玉珠，开启在右，关闭在左。透明提取过程中第一张素材金框过厚，经过第二次图像编辑去掉金属浮雕与阴影后才实装。

最终图集为 `toggle_jade_v2.png`，1855×848 RGBA，保留工具原始透明度。运行时使用统一 432×200 的局部 UV：开启 (710,187)，关闭 (710,460)，映射为 26×12 GUI 像素。左右状态外框及按钮布局保持一致，右内边距 5，整行高 22，纵向按中心对齐。

用户将范围限定为切换按钮后，又明确增加移动条的优化。因此本轮只调整开关与移动条的外观。设置页分类分界线的新增绘制已撤回，其他行框、文字、背景和布局不调整。效果图只作为开关素材参考，不整张覆盖游戏界面。

移动条采用同风格圆玉珠滑块，另用 imagegen 从最终开关素材提取透明滑块。保留原始 1254×1254 RGBA，以 (417,417,420,420) UV 映射为 8×8 GUI 像素。轨道为原生生成的两像素细哑金槽及柔和玉色填充。滑块端点改为与原版点击映射一致的 x+4 和 x+width-4；取值范围、步长、键盘操作及配置保存规则沿用原实现。
