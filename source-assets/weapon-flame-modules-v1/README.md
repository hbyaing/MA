# 异火模块贴图 v1

2026-09-28，使用内置 image_gen，以用户提供的轨迹和碎焰为材质参考生成。四张独立 RGBA PNG，透明背景与透明缺口；橙红外缘、金黄主体、浅黄亮芯，强调块状轮廓与阶梯边缘。

| 文件 | 用途 | 建议可见长度比例 |
|---|---|---|
| main_arc.png | 粗厚的主体弧段，旋转并沿运动轨迹排列 | 1.00 |
| transition_arc.png | 较短、边缘破碎的过渡弧段 | 0.60 |
| tail_fragment.png | 暗橙色短弧块，用于末段衰减 | 0.22 |
| scatter_particle.png | 独立火焰块，用于命中与脱落 | 0.12 |

这些比例是起始调参建议，按有效像素边界计算长度，不按整张画布计算。四张图分别是一种模块，不是动画帧或一条完整挥剑轨迹。尾端已二次修订，减小亮芯并补足透明边距。

## 导入和组合

- PNG 为高分辨率生成原图，带像素块风格，并非严格统一 texel 网格的小尺寸终版。可以作为独立透明纹理导入；正式发布前仍建议按目标屏幕尺寸制作低分辨率导出，并检查远近景读图效果。
- manifest.json 记录实际尺寸、透明像素比例、有效区域、推荐区域 UV 和区域中心枢轴。有效区域使用 alpha > 8，附 2 像素保护边；UV 原点为左上，具体引擎可能需要翻转 V。
- 使用区域 UV 时，应按区域宽高比建立面片；不使用区域 UV 时，需要在面片缩放中补偿留白。尾端留白较多，尤其需要注意。
- 初始使用最近邻采样和 CLAMP_TO_EDGE，按运行时材质的透明混合约定配置；PNG 未人为预乘 alpha。亮度可由特效材质控制。
- 沿轨迹交替放置主体和过渡段，保留部分间隙；末端逐步替换为尾端块，降低透明度并适度缩小。散射粒子独立设置速度、旋转、寿命，避免沿单一直线拉长。

## 验证边界

已检查四张文件可解码、具有透明通道和透明边界，并记录 SHA256。随后已接入 Java 异火渲染器：运行资源位于 `src/main/resources/assets/wuxingxiantu/textures/effect/modular_v1/`，使用本目录原图的有效 UV 区域；未改变 PNG 像素。主体、过渡、尾端沿路径按距离组合，低透明度轨迹改用尾端块，散射用于命中和脱落。具体构建与实机验证结论见 `docs/audits/current/20260928_MODULAR_FLAME_INTEGRATION.md`。未制作 Photon 配置。

prompts.json 保留完整生成提示词与尾端修订提示词；引用图片路径属于生成时的临时文件路径，使用成品无需这些参考文件。manifest.json 为中立元数据，不是特定引擎可直接加载的配置。
