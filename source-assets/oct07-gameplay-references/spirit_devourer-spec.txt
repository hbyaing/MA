请根据当前《五行仙途》Mod源码，为已经完成模型的自然生成怪物【噬灵虫】进行完整实装。

项目环境以当前源码为准，不要凭空新建与现有架构冲突的系统。开始前先检查项目中：
1. 生物实体注册方式
2. GeckoLib 动画接入方式
3. 灵植注册与生长阶段实现
4. 灵壤系统
5. 灵液、灵肥、炼丹材料等现有物品体系
6. 自定义粒子系统
7. LootTable、BiomeModifier / 自然生成相关实现
8. config / gamerule / mobGriefing 相关处理

优先复用现有注册器、工具类和数据生成结构。

====================
一、噬灵虫基础定位
====================

名称：噬灵虫
类型：低阶群居妖虫、敌对节肢生物、灵田害虫
定位：炼气期即可遇到的前期普通怪，不是精英怪，不是Boss。

建议基础属性：
- 最大生命值：12
- 攻击力：3
- 护甲：2
- 移动速度：0.28
- 追踪距离：16格
- 击退抗性：0.1
- 经验值：2~4
- 攻击距离约：1.2~1.4格
- 攻击间隔约：1.2秒

碰撞箱根据现有模型实际比例调整，目标约：
宽 0.65 格
高 0.45 格

不要为了严格满足数值破坏模型实际比例。

====================
二、基础AI
====================

噬灵虫不要使用“纯僵尸式AI”。

平时行为：
- 在地面缓慢游荡
- 六足爬行
- 优先寻找附近灵植
- 没有目标时正常随机游荡
- 不主动超远距离追击玩家

玩家靠近过近、攻击噬灵虫，或者噬灵虫受到玩家伤害后才进入攻击状态。

攻击方式：
身体短暂后缩，然后快速前扑咬击。

单只威胁较低，核心威胁来自群体。

====================
三、群体仇恨
====================

噬灵虫受到玩家攻击时：

搜索周围约8格范围内其他噬灵虫。

让附近噬灵虫共同将该玩家设为攻击目标。

效果：

攻击一只噬灵虫
→ 附近虫群同时进入敌对状态。

不要无限链式传播。
限制搜索距离，避免大量实体AI开销。

====================
四、寻找灵植
====================

噬灵虫核心特色是【吸食灵植】。

空闲状态下周期性搜索附近灵植。

推荐搜索半径：
10~12格。

不要每tick扫描方块。

必须使用低频扫描、缓存目标或其他低开销实现。

如果项目已有灵植统一接口、Tag、Block基类或Registry集合，优先复用。

目标优先级：

成熟灵植
>
未成熟灵植
>
普通游荡

找到灵植后移动到灵植根部附近。

====================
五、吸灵行为
====================

到达灵植后停止移动。

播放：

feed

吸灵动画。

吸食持续约3秒。

吸食过程中：
- 面朝灵植
- 触角表现出感知灵气的动作
- 腹部灵囊逐渐变亮
- 可生成少量青绿色自定义灵气特效

不要使用大量Minecraft原版粒子。

如果已有粒子库，优先从粒子库选择适合的：
灵气丝
能量丝
小型流光
等效果。

粒子运动方向：

灵植
→
噬灵虫腹部

数量要少。

====================
六、灵植损害
====================

不要直接把灵植吃掉。

如果灵植已经成熟：

成熟阶段
→
倒退1个生长阶段。

例如：

stage 5
→
stage 4

不要：
成熟植物
→
直接空气。

如果灵植本身不支持倒退生长阶段，则根据当前灵植实现设计兼容方案。

一株灵植被吸食后添加约30秒保护/冷却。

避免多只噬灵虫连续把同一株植物快速吸干。

必须尊重：

mobGriefing

如果：

mobGriefing = false

则噬灵虫可以执行寻找、吸食动画和进入饱灵状态，
但禁止真正修改灵植方块状态。

====================
七、饱灵状态
====================

成功完成一次吸灵后：

噬灵虫进入【饱灵状态】。

持续时间建议：
45秒左右。

范围可控制在：
30~60秒。

需要保存状态并同步到客户端。

饱灵状态表现：

普通状态：
腹部光芒较暗。

饱灵状态：
腹部青绿色灵囊明显变亮。

优先通过：
材质切换
Emissive Layer
RenderLayer参数
GeckoLib渲染层
或项目当前已有方案实现。

不要使用大量常驻粒子表示状态。

饱灵状态下：

移动速度 +10%

不要增加攻击力。

====================
八、掉落机制
====================

新增或复用以下材料：

1. 虫甲碎片
常见材料。

掉落：
0~2个。

2. 噬灵虫囊
噬灵虫储存灵气的囊器。

普通状态掉率：
约15%

饱灵状态掉率：
约40%

3. 微量灵液

优先检查项目是否已经存在类似：
灵液
灵液滴
低阶灵液
灵气液体材料

如果已有合适物品，直接复用，不要重复创建。

普通状态：
不掉落。

饱灵状态：
约15%掉落。

如果LootTable无法方便读取饱灵状态，可以通过：
LootCondition
实体NBT/数据字段
自定义LootCondition
或实体死亡时附加逻辑实现。

优先采用符合Forge数据驱动结构的方案。

====================
九、侧爬闪避
====================

增加一个轻量级特色行为：

噬灵虫受到伤害时，有约15%概率执行一次短距离侧向闪避。

位移距离：
约0.3~0.5格。

内部冷却：
约2秒。

要求：
- 不能穿墙
- 不能进入实体方块
- 不能掉进明显危险位置
- 不是真正瞬移
- 尽量表现成快速横向爬动

如果实现代价过高，可先使用短时间横向速度替代。

====================
十、动画
====================

检查现有噬灵虫模型中的动画名称。

至少接入：

idle
walk
attack
feed
hurt
death

如果模型动画命名与上述不同，以模型真实动画名称为准。

动画逻辑：

idle：
触角缓慢摆动，身体轻微起伏。

walk：
六足爬行。

attack：
短暂后缩 + 前扑咬击。

feed：
停在灵植旁吸收灵气。

hurt：
短促缩身。

death：
身体失去支撑、虫足收缩。

不要重复播放攻击动画或因状态机冲突造成动画闪烁。

====================
十一、自然生成
====================

噬灵虫可以自然生成于：

- 森林
- 草原
- 繁茂洞穴
- 灵植较多区域
- 灵气浓郁区域

普通环境生成权重较低。

建议：

普通区域：
权重约6
群体数量2~3

灵植/灵壤生态区域：
权重约14
群体数量2~4

如果Forge自然生成系统不方便动态根据附近方块调整权重，
不要强行在BiomeModifier里扫描世界。

可以改为：

普通自然生成
+
生成条件中适度检查附近灵植/灵壤
+
提高允许生成概率。

亮度条件建议：

blockLight <= 9

允许白天阴暗树林中偶尔出现。

不要大量生成在：
- 村庄核心区域
- 玩家出生点附近
- 明亮室内环境

需要遵守正常敌对生物生成规则。

====================
十二、生成性能
====================

必须注意性能。

禁止：
- 每tick扫描10~12格全部方块
- 每tick寻找几十个灵植
- 每tick查询整个虫群
- 不受限制的PathNavigation重算

寻找灵植建议：
每20~40tick尝试一次。

如果已经锁定合法目标，则不要重复全范围搜索。

群体仇恨只在：
受到伤害
等事件触发时查询。
