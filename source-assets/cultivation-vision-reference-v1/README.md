# 内视页参考图 v1

使用内置 image_gen 生成第二页参考图。

- `vision-reference.png`：生成的内视页参考图，1672×941。
- `target-original.png`：本轮用户提供的原始内视页截图。
- `generation-prompt.txt`：实际生图提示词。
- 风格参考：`../cultivation-ui-reference-split-v1/reference-original.png`。

内容保持原页六个分区：修炼状态、修行根基、修炼操作、灵根、领域、异火。
采用与已选背包页一致的深色水墨侧栏、宣纸区域及金色组件；导航选中内视。

本轮只生成参考图，尚未拆分第二页素材，也未修改界面代码。图中字体、物品图标和背景为设计表达，不能将整图作为运行时交互界面直接贴入游戏。
