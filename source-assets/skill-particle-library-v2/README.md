# 五行仙途 · 技能粒子库 V2

本版解决V1的整套配方重复和主纹样滥用。沿用源码139项，改为139套逐项编排的材质、主次层和时间线。基础材质由60种增加到138种，新增78种；动画材质64种，每组16帧。完整程序化生成器随包放在generator，重建需要原工程src。

## 使用

- `preview/index.html` 双击打开：搜索技能、换色、播放、拖动、导出配方；新增“主形/次形/余韵”隔离和灰度对照。可以不依赖颜色判断技能差异。
- `recipes/` 每个ID一份完整配方，含主次角色、颜色角色、错峰延迟及归一化路径采样。`catalog/diversity.json` 为V1/V2重复统计。
- `resourcepack/` 为Minecraft 1.20.1格式15资源包。透明材质256×256，动画4×4共16帧，每帧128×128。白色straight-alpha，按行播放。
- `photon/projects/recipes__技能ID.fxproj` 为该技能的Photon可编辑样片；`materials__材质ID.fxproj` 为单材质样片。每个项目内有完整材质库。
- Photon 1.1.17 / LDLib 1.0.42：启用随附资源包后打开项目。运行资源ID如`wuxingxiantu_vfx:recipes/ermei_05`。V2与V1沿用材质命名空间，制作时建议只启用当前版本。

## 差异化重点

目魇用虹瞳、透镜与棱光；耳魅用声叉、频谱墙与回声梭；鼻嗔用毒针、孢簇与香带；舌饕用舌镰、饕口与垂酸；身淫用晶须、刺冠与神经丝；意惑用折镜、旧影足迹与心结；彭倨用古钱、金翅与方印；彭质用酒带、腹褶与吸盘；彭矫有五种独立核纹；心魔用残面、妄瞳、倒刺链与裂心。

九种异火各有独立主形：赤流焰锋、熔金液脉、枯骨寒焰、木芽青焰、碧海涡焰、紫霄电焰、日珥、冥火幽帷、涅槃凤翎。功法按剑意、生长、护壳、身法等划分；心法保留低密度修炼表现。共同火花仅作次要点缀。

## 数据与验证边界

V1最频繁的魂丝用于40项；V2最高频材质用于10项。忽略颜色、顺序和参数后，独立纹样集合38→131；忽略ID和颜色的动作组合39→139。这些数字只是复用检查，不代表审美评分。

预览与Photon样片读取同一套采样路径。Photon为每条曲线建立独立粒子发射器，使用现有原生字段导出位置、速度、大小、旋转和阶段颜色；复杂配方抽样到不超过32个发射器。曲线速度为离散导数，原生引擎积分与Billboard朝向可能使画面与浏览器有差异。地面压扁图、墙与束仍是选材构图，实际三维技能需对应模型、平面、Beam/Trail或实体接入。

完成PNG透明边界、动画帧、路径有限值、素材引用、NBT读回和浏览器检查。**本轮未加载Minecraft、未做游戏内播放和性能测试，未修改生产技能或伤害判定。** Boss真实前摇和多段判定仍以源码为准，样片时间线是美术设计值。V1目录与原ZIP保留。
