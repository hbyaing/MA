# 本轮灵根图标源资产

七种图标使用 imagegen 根据原有五行灵根的菱形、卷角金属边框与中央中文标识制作，统一透明背景。金与土分别为明金、铜棕，木为青绿，水为深蓝，火为朱红，雷为紫色，异为青蓝。要求中央汉字清晰、边缘圆滑，无文字矩形底板；只绘制徽记，不绘制UI、场景或外部粒子。

`*-generated.png` 为生成原图，`*-256.png` 为按透明有效边界归一后的256×256游戏资源，`*-before.png` 保存替换前的对应资产。最终alpha、尺寸和内视页真实渲染结果在 `reports/alchemy-followup-20261014` 验证；转换脚本为 `tools/build_root_icons_hd.py`。

丹灰直接使用用户提供的透明原图制作32×32贴图，未用生成图替代参考内容。
