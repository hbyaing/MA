# Boss 粒子库 V3 · 模型风格、清晰度与真实范围

当前入口：`source-assets/skill-particle-library-v3/preview/index.html`。

本轮按用户对模糊、Boss 风格不符、技能范围不适配的反馈，读取当前生产源码、GEO、贴图和渲染配置，制作独立 V3 Boss 库。V2 的普通功法、御剑、神通、被动、符箓、异火与仪式素材继续保留。

## 交付内容

- 10 类 Boss 的实际模型、原贴图、静态网格和骨骼锚点；实体箱与可见模型包围盒分别记录。
- 77 个 Boss 技能、173 个阶段/距离/目标分支、1649 个源码事件。单次技能轨迹基于明确合成输入，所有事件完整保留。
- 50 张新的预着色专属材质，256px 母版、128px 运行版本；各 Boss 具有弹体、命中、核心、边界、扫击五种角色。32px 检查保留不透明主体。
- 223 对原生 Photon FX/项目：50 个材质样片、173 个分支场景；保留 1031 个平面危险区域，使用 501 套独立尺寸与位置的地面遮罩。
- 无联网依赖的交互预览，可切换俯视/正视、阶段、灰度、名义范围、实际边界与判定高度，导出当前场景完整参数。

## 风格纠正

彭倨取腐败巨颅、破颚与财宝护盾；彭质取紫黑裂腹与触口；鼻嗔取灰粉腺肉和黄绿黏毒；耳魅取骨白螺耳与青绿声纹；意惑取无定形紫云及方形记忆碎片；彭矫取白色魂心、五色傩面与袍摆；心魔取黑曜裂面、赤心和妄链。每项均保存实际骨骼及贴图证据。

## 范围纠正

线段使用实际圆头胶囊判定，width 为全宽并加 0.5 格总容差；环使用真实内外半径，保留中空区；扇区保留源角度和半径容差；移动、追踪弹及多段攻击按源码时间推进。双壁合鸣名义缺口为7格，圆头容差后的局部安全宽度为4.7格。彭矫缺口环按实际胶囊线段绘制，不把注释中的60度当成实际安全角。凝视按视线与遮挡判定，不提供虚构固定半径。

Photon 原生地面贴图以一纹素向内收边，防止栅格化覆盖安全区；实际边界保留在配方格坐标中，运行时优先用真实 Mesh/Decal。原生四边形尺寸已核对本地 Photon 1.1.17 类：顶点为 ±startSize，故全宽/全高除2；Horizontal 模式为 X 轴正90度。

## 验证入口

- `reports/skill-particle-library-v3/range-validation.json`：独立多边形/解析判定抽样及关键安全缺口回归。
- `reports/skill-particle-library-v3/browser-validation.json`：77技能、173场景、519个几何画面抽样；原始模型、搜索、导出、窄屏布局。
- `reports/skill-particle-library-v3/file-validation.json`：源码哈希、材质、模型、原生贴图引用和范围遮罩。
- `reports/skill-particle-library-v3/photon-schema-evidence.json`：本地安装版本尺寸与朝向的只读检查。
- `reports/skill-particle-library-v3/delivery.json`：ZIP大小、哈希与完整性。

## 边界

本轮交付是独立制作库，未修改生产 Java、技能伤害、模型、现有实例，也未执行 Gradle、GameTest 或启动 Minecraft。独立 Java 存根使用当前原始技能程序和纯几何回放，不能代替游戏测试。

浏览器为真实资源的静态绑定姿势，不播放 GeckoLib 动画。心魔一期使用玩家动态皮肤，预览显示二期无相模型并明确标注。合成输入不穷尽所有目标路线、地形遮挡、玩家破招与跨技能残留区域；Photon 速度积分是离线样片近似，需运行时以实际事件、位置和取消状态驱动。

原生单场景最多51个发射器；为保留危险边界，本轮未按32个发射器删减。游戏接入时应合批边界几何，优先减少装饰层，并实际测量性能。

## 重建

工程内运行 `tools/vfx_library/build_v3.py`；文件验证运行 `tools/vfx_library/validate_v3.py`，几何验证运行 `tools/vfx_library/check_ranges_v3.py`。浏览器验证使用 `tools/vfx_library/check_preview_v3.cjs`。`--package-only` 仅打包当前已经验证的库。
