# 装备空槽背景素材

按用户提供的原图直接裁切，未使用生图重绘，未改动 Java 或运行时资源。

左列从上到下：头盔 helmet、胸甲 chestplate、护腿 leggings、靴子 boots。
右列从上到下：道袍 dao_robe、御剑 flying_sword、原版盾 vanilla_shield。
盾槽对应原版副手槽位语义，实装时仍保留副手原有物品行为。

## 文件

- raw/：原尺寸裁片，完整保留原图形状与背景。
- textures/256、128、64、32、18：每套七张正方形 PNG；将含 2px 安全边距的整张裁片缩放，不重新绘制。
- atlas/equipment_slots_64.png：256×128 图集，64px 单格，顺序与 manifest 一致，第八格透明。
- manifest.json：名称、用途、原图坐标、输出路径、图集坐标。
- contact-sheet.png：七个槽位及实际 32px/18px 缩小效果。

图片包含深色底、金色边框和空槽图案，保持不透明。原图没有真实透明通道。
后续实装时建议仅在空槽显示中央装备图案，物品与数量交由 Minecraft 渲染。
18px 下复杂线条会因缩小变弱；正式接入时应结合实际槽位显示尺寸调整，尚未游戏内验证。
